# 🌿 WILLOW AI

### AI-Powered Stock & Financial Intelligence Platform

**WILLOW AI** is an intelligent financial analysis platform that transforms complex stock-market and financial data into clear, actionable insights.

It combines **market data, technical analysis, fundamental analysis, portfolio intelligence, and AI-powered reasoning** to help users better understand stocks, evaluate risks, identify opportunities, and make more informed financial decisions.

> **WILLOW AI — Turning Market Data into Financial Intelligence.**

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/WILLOW-AI.git
cd WILLOW-AI
```

### 2. Install backend dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 3. Install frontend dependencies

```bash
cd frontend
npm install
```

### 4. Configure environment variables

Create a `.env` file and add the required API keys:

```env
MARKET_DATA_API_KEY=your_api_key
AI_API_KEY=your_api_key
DATABASE_URL=your_database_url
```

### 5. Start the application

Backend:

```bash
uvicorn main:app --reload
```

Frontend:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
